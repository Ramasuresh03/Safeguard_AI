Overview

What is Women Safety System?

Women Safety System is an AI-Powered Women's Safety Framework that operates without any human interaction. Traditional safety devices (panic buttons, apps) require the victim to act — but in a real attack, that's often impossible. Women Safety System solves this by automatically monitoring physiological data (Heart Rate, Motion, Temperature) and instantly alerting a Guardian Dashboard if a threat is detected — faster than any human can respond.

5,000+ Training Scenarios

3-in-1 Sensor Fusion

Machine Learning

Algorithms & Models Used

Women Safety System uses a Random Forest Classifier — an ensemble ML algorithm that builds multiple Decision Trees and averages them for high accuracy. Instead of relying on a single sensor (which causes false alarms), we use Multi-Sensor Fusion: Heart Rate, Motion Index, and Body Temperature analyzed together for context-aware sensing.

  • ✓ Safe High HR + Rhythmic Motion → Exercise detected
  • ⚠ Danger High HR + Chaotic Motion → Panic detected
  • ↑ Warning Temperature spike → Fight-or-Flight response
📈

Performance

Model Accuracy

The Random Forest approach significantly improves detection accuracy while reducing false positives compared to traditional rule-based systems. Trained on a synthetic dataset of 5,000 scenarios spanning Rest, Exercise, and Panic states, the model reliably distinguishes a gym workout from a genuine attack.

System Design

Technical Architecture — The 3 Layers

01

Input Layer

The Virtual Device

A Python Simulator (smart_watch.py) acts as a Smart Watch, generating real-time sensor data (HR, Motion, Temp) and sending it via HTTP POST every second.

Python requests JSON
→
02

Processing Layer

The AI Brain

A Flask server (app.py) hosts the trained Random Forest model. It receives sensor data, runs a prediction, and returns 0 (Safe) or 1 (Threat) in milliseconds.

Flask scikit-learn joblib
→
03

Application Layer

Guardian Dashboard

A real-time web dashboard polls the server every 0.5s via JavaScript Fetch API, updates live Chart.js graphs, and triggers emergency animations on threat detection.

JavaScript Chart.js CSS3
