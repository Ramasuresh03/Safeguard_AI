# 🛡️ IoT-Based Women Safety System

An **IoT-based Women Safety System** designed to monitor a user's health and safety parameters in real time using a smartwatch simulator. The system receives simulated smartwatch data such as **heart rate, SpO₂, pulse, and other safety-related parameters**, processes the data through a Flask backend, displays live information on a women safety dashboard, predicts potential threats, and generates alerts when suspicious or dangerous conditions are detected.

---

## 📌 Project Overview

The **IoT-Based Women Safety System** combines IoT simulation, real-time monitoring, machine learning, and web technologies to provide an intelligent safety monitoring platform.

The project consists of two major components:

### ⌚ 1. Smartwatch Simulator

The smartwatch simulator acts as an IoT wearable device. It generates and sends real-time sensor values such as:

* **❤️ Heart Rate**
* **🫁 SpO₂ (Blood Oxygen Level)**
* **💓 Pulse**
* **🌡️ Other health/safety parameters**
* **📍 Location/safety-related information**

These values simulate the data that could be collected from an actual smartwatch or wearable IoT device.

### 🖥️ 2. Women Safety Dashboard

The Women Safety Dashboard is a web-based application developed using **Flask**.

The dashboard receives the values generated by the smartwatch simulator through the backend and continuously updates the displayed values.

The system also analyzes the incoming data to:

* **Monitor the user's current condition**
* **Detect abnormal patterns**
* **Predict potential threats**
* **Display the current threat status**
* **Generate safety alerts**
* **Provide real-time monitoring through the dashboard**

# 🎯 Key Features

## ⌚ Smartwatch Simulation

The project simulates an IoT smartwatch that continuously generates health and safety data.

Example parameters include:

```text
Heart Rate: 82 BPM
SpO₂: 98%
Pulse: 81 BPM
```

The generated values are transferred to the Women Safety System for further processing.

---

## 📊 Real-Time Dashboard

The Women Safety Dashboard displays the incoming smartwatch data in real time.

The dashboard can monitor:

* Heart rate
* SpO₂
* Pulse
* Safety status
* Threat status
* Other available sensor information

The displayed values are dynamically updated as new smartwatch data arrives.

---

## 🤖 Threat Prediction

The incoming sensor data is analyzed by the system to identify potentially abnormal or dangerous conditions.

The system can classify the current situation into different safety states, such as:

```text
NORMAL
WARNING
THREAT
CRITICAL
```

The prediction mechanism helps identify situations that may require immediate attention.

---

## 🚨 Alert Generation

When the system identifies a potentially dangerous condition, it generates an alert.

Example:

```text
⚠️ WARNING:
Abnormal health/safety parameters detected.

🚨 THREAT ALERT:
Potential danger detected. Immediate attention required.
```

The alert mechanism helps ensure that abnormal situations are highlighted immediately.

---

# 🧠 Machine Learning Component

The project includes a machine learning component for threat prediction.

The model is trained using a dataset containing relevant health and safety parameters.

Example input features may include:

```text
Heart Rate
SpO₂
Pulse
Movement/Safety Parameters
Other Sensor Values
```

The trained model is used by the Flask application to analyze incoming smartwatch data and predict the corresponding safety/threat condition.

# ⚙️ Installation

## 1. Clone the Repository

```bash
git clone https://github.com/Ramasuresh03/Safeguard_AI.git
```

```bash
cd Safeguard_AI
```

---

## 2. Install Women Safety System Dependencies

```bash
cd "Women_Safety_System"
```

```bash
pip install -r requirements.txt
```

---

## 3. Start the Women Safety Dashboard

Run:

```bash
python app.py
```

The Flask application will start locally.

Open the URL displayed by Flask in your browser.

---

# ⌚ Running the Smartwatch Simulator

Open another terminal and navigate to:

```bash
cd "Smartwatch Simulator"
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Then start the smartwatch simulator:

```bash
python smartwatch.py
```

The simulator will generate smartwatch sensor values and send them to the Women Safety System.
